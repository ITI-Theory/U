# Papers Omnibus UAT Package

## Copy This Into NotebookLM

```text
Read papers-omnibus-nlm-uat.md and execute every Sherlock, Harry Potter, and Cookie Monster item. For each item, use this exact format: ITEM, STATUS (PASS/FIX/OPEN), FINDING, EVIDENCE (exact source PDF filename and page number). Do not repeat the worksheet or list headings without an answer. ```
```

Upload every file in this folder first, then paste only the instruction above.

This folder is a complete NotebookLM UAT package. It is generated by:

```bash
cd U
make uat-stage-papers
```

## What To Upload

Upload every file in this staged folder to a fresh **private** NotebookLM
notebook. The files include:

- candidate PDFs;
- `papers-omnibus-nlm-uat.md`, the versioned UAT worksheet and evidence log;
- `MANIFEST.md`, which identifies the exact source artifacts and SHA-256 hashes.
- `PAPERS.md`, a readable generated view of the master registry;
- `BUILD_CONTEXT.md`, labeled build, format, TeX, Make, and validation sources;
- `papers-build-review.md` and `dev-handover.md`, context for architectural review.

## What To Do In NotebookLM

The instruction above directs NotebookLM to `papers-omnibus-nlm-uat.md`, which
contains every question, evidence rule, completed finding, and acceptance
decision. Use `PAPERS.md` for registry questions and `BUILD_CONTEXT.md` plus
the two review documents for build/format questions. Do not use chat history
as a release input.

## What To Do After NotebookLM

1. Add NotebookLM's cited findings to the matching status blocks in
   `papers-omnibus-nlm-uat.md`.
2. If an item is `FIX`, make a narrow source correction, rebuild only affected
   candidates, rerun `make uat-stage-papers`, and repeat only that worksheet
   item.
3. If all Sherlock and Harry Potter items pass, record the acceptance decision
   in the worksheet and continue with the Papers track in `Dist/README.md`.
4. Cookie Monster reader-bridge items may be deferred only when marked
   non-blocking in the worksheet.
