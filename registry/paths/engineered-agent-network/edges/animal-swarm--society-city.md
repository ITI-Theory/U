The zoom from animal swarm to society/city keeps distributed propagation but changes the medium radically `interpretive`. A swarm display can often use positions, velocities, local-neighbour rules, density, and noise. A city needs streets, buildings, markets, media, law, transport, archives, platforms, service networks, class boundaries, neighbourhoods, and institutional procedures `derived-under-assumptions`. The new kernel $G_{\mathrm{city}}(x,x';t)$ is therefore not only a distance decay. It is a layered response function whose channels include proximity, mobility, communication, trust, authority, and infrastructure `open-hypothesis`.

What survives from the swarm is the idea that local changes can become visible as a larger pattern: congestion, imitation, rumour, epidemic warning, protest movement, fashion, evacuation flow, or service failure `interpretive`. What is integrated out is the animal-agent trajectory as the main display. The city still contains persons, groups, vehicles, animals, and devices, but the atlas now shows encounter rates, channels, capacities, bottlenecks, boundary rules, and memory stored in built form or procedure `derived-under-assumptions`.

The edge is especially useful for the Engineered Agent Network path, where drones, robots, or software agents may feed into urban infrastructure. It is also a warning. A city is not a swarm with better buildings; it is a social and material system with meanings, institutions, inequalities, and histories `interpretive`. The renderer should add networks, roads, zones, media links, and civic boundaries, not merely scale up moving dots `open-hypothesis`.
