# Penrose Road to Reality baseline index

Use `registry/catalogues/penrose-road-to-reality.yaml` as a 4D baseline catalogue. It gives chapter ranges, selected section anchors, standard equations, mapped registry levels, and the [T]-Theory comparison class. It never claims Penrose endorses [T]-Theory.

## How to use it

1. In baseline mode, show the Penrose chapter/section and standard equation.
2. In compare mode, add the mapped P-paper or dataset with its status label.
3. Use `docs/agent/THEORY-STATUS.md` labels: `kernel-verified`, `derived-under-assumptions`, `simulated`, `empirical-result`, `interpretive`, or `open-hypothesis`.
4. Treat chapter titles and equations as index facts; avoid source prose.
