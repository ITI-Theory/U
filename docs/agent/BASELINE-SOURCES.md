# Baseline Sources

Books on the author's machine that supply the "4D baseline" (ordinary,
sourced science) for each level, and the style models for the Field Atlas.
Paths are local; the books themselves are never committed. Index facts
(chapter numbers, titles, standard equations) are fine; quotations and
copied figures are not, except where the licence column says CC BY.

## Style models for the Atlas

- OpenStax: learning objectives, numbered figures, example and "check your
  understanding" boxes, key terms, key equations, summary, review questions.
  Borrow the style, not the name or logo (trademark).
- *The Cosmic Perspective*: amateur-astronomy voice, "think about it" boxes,
  scale diagrams.
- Klee's notebook diagrams: annotated line-and-arrow plates for dynamics.
